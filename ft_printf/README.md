Description:

	Goal with this project was the reproduce the functionality of the printf function from stdio.h, with the exception of the buffer management of the original.
	It must handle the conversions cspdiuxX%.

Instructions:

	Run make to compile the functions into libftprintf.a. Make also can be ran with *make clean* to remove the .o files, *make fclean* to remove .o files and libft.a and *make re* which performs *fclean* followed by *make*.
	To run the header file in your C source use #include "ft_printf.h".
	Compile using "bash cc -Wall -Wextra -Werror main.c libftprintf.a".
